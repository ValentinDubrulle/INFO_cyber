# Digest cybersécurité — 12/11/2026

## À retenir

- Europol et les forces de l'ordre de neuf pays ont démantelé les infrastructures de Gootloader, CastleRAT et StealC en saisissant des centaines de serveurs et de noms de domaine. En parallèle, ConnectWise enquête sur une campagne active exploitant des accès ScreenConnect compromis pour infecter les clients de plusieurs MSP.
- Plusieurs vulnérabilités critiques d'exécution de code ou d'élévation de privilèges ont été signalées, notamment dans Apache HTTP/2 (CVE-2026-119618), PTC Windchill et FlexPLM (CVE-2026-126325), ainsi que dans Zoom Workplace (CVE-2026-108186). N-able investigue également des failles RCE touchant les installations sur site de N-central dont l'API héritée est activée.
- Google Cloud alerte sur trois failles par canal auxiliaire affectant les processeurs AMD Turin dans ses machines virtuelles, bien que des mesures d'atténuation protègent déjà l'hôte et les VM entre elles. Par ailleurs, la campagne de phishing « Opération CloudFire » contourne les détections à l'aide d'invitations de calendrier et de proxies actifs pour dérober des sessions Google d'entreprise.

## Vulnérabilités

### Failles processeurs AMD Turin dans Google Cloud : fuite de données en VM
Google Cloud avertit que les machines virtuelles (VM) fonctionnant sur des puces AMD Turin sont vulnérables à trois failles de sécurité CPU par canal auxiliaire (side-channel). Google a déjà déployé des mesures d'atténuation pour protéger les attaques entre les VM ainsi qu'entre les VM et l'hôte. Néanmoins, à l'intérieur d'une même machine virtuelle, un attaquant exécutant du code sur le même cœur de processeur pourrait inférer des données provenant d'autres processus ou du noyau. Pour se prémunir contre ces risques, les administrateurs doivent impérativement installer un correctif sur l'OS invité et procéder à un arrêt-redémarrage (stop-and-start) de la VM.

[The Hacker News](https://thehackernews.com/2026/11/google-cloud-warns-three-amd-turin-cpu.html)

### Failles RCE root et SYSTEM dans N-able N-central exposé sur Internet
N-able a annoncé enquêter sur une divulgation publique faisant état de nouvelles vulnérabilités affectant les versions sur site de sa solution N-central, y compris la version 2026.4.1 HF2 pourtant mise à jour. Selon les premiers examens techniques de l'éditeur, le problème côté serveur dépend d'une configuration non définie par défaut dans laquelle la fonction « Legacy API » est activée et directement exposée sur Internet public. Les exploits découverts permettent d'aboutir à une exécution de code à distance (RCE) avec les privilèges root et d'obtenir un accès Windows SYSTEM.

[The Hacker News](https://thehackernews.com/2026/11/new-n-central-exploits-work-against.html)

### Correction d'une vulnérabilité critique d'exécution de code dans PTC Windchill et FlexPLM
L'éditeur PTC a déployé des correctifs de sécurité afin de combler une vulnérabilité critique répertoriée sous la référence CVE-2026-126325, qui impacte ses logiciels Windchill et FlexPLM. Cette faille reçoit un score CVSS v4 de 9.2 sur 10.0, ce qui souligne sa sévérité importante. Sur le plan technique, le problème découle d'une validation d'entrée inadéquate combinée à une désérialisation de données non fiables. En cas d'exploitation réussie par un acteur malveillant, cette faiblesse logicielle permettrait d'aboutir à l'exécution de code à distance (RCE) sur les systèmes hébergeant les instances vulnérables. L'application des correctifs fournis par PTC est nécessaire pour protéger les déploiements affectés.

[The Hacker News](https://thehackernews.com/2026/11/ptc-patches-critical-windchill-and.html)

### Vulnérabilité critique d'exécution de code à distance dans Apache HTTP/2
Une faille de sécurité critique désignée sous l'identifiant CVE-2026-119618 a été découverte dans le module mod_http2 du serveur HTTP Apache. Cette vulnérabilité offre la possibilité à un attaquant distant et non authentifié d'exécuter du code arbitraire sur le serveur affecté. Selon Red Hat, qui intègre le composant dans Red Hat Enterprise Linux, seuls les serveurs ayant activé la prise en charge de HTTP/2 sont exposés. La faille concerne les versions 2.4.55 à 2.4.70 et est corrigée dans la version 2.4.71 récemment publiée.

[The Hacker News](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html)

### Faille critique d'élévation de privilèges dans Zoom Workplace
Zoom a publié des correctifs de sécurité afin de combler deux failles affectant le logiciel Zoom Workplace pour Windows. L'une d'elles, référencée CVE-2026-108186 et dotée d'un score CVSS critique de 9.6, découle d'une validation incorrecte des entrées utilisateur. Cette vulnérabilité sévère peut permettre à un attaquant distant et non authentifié d'obtenir une élévation de privilèges sur les systèmes concernés. Il est fortement conseillé de déployer les mises à jour sans délai.

[The Hacker News](https://thehackernews.com/2026/11/critical-zoom-workplace-flaw-could.html)

### Faille critique pré-authentification provoquant le crash de serveurs MongoDB
Une faille de sécurité critique pré-authentification a été identifiée dans MongoDB Server sous la référence CVE-2026-118383. Elle permet à un attaquant non authentifié d'envoyer deux requêtes spécifiques capables de provoquer le crash du serveur de base de données. L'interruption de service survient uniquement si le serveur ciblé fait partie d'un jeu de réplicas et qu'il est ultérieurement désigné pour devenir le serveur principal alors qu'il accuse un retard de synchronisation sur certaines modifications récentes. MongoDB a publié des versions corrigées pour neutraliser ce comportement.

[The Hacker News](https://thehackernews.com/2026/11/critical-pre-auth-mongodb-flaw-cve-2026.html)

### Node.js corrige 16 vulnérabilités affectant HTTP/2 et la fuite de mémoire
Node.js a publié des correctifs pour 16 vulnérabilités, dont deux failles liées à l'implémentation native de HTTP/2. La première permet à des clients non authentifiés de faire planter les serveurs exploitant HTTP/2 sur les branches 24.x et 26.x. La seconde peut conduire le serveur à renvoyer des fragments de sa mémoire aux clients, exposant potentiellement des données ou des réponses destinées à d'autres connexions. Les versions sécurisées 22.23.5, 24.22.3 et 26.13.1 ont été mises à disposition pour l'ensemble des branches maintenues afin de corriger ces dysfonctionnements.

[The Hacker News](https://thehackernews.com/2026/11/nodejs-fixes-16-flaws-including-http2.html)

### eMudhra révoque 8 certificats suite à des clés privées mal gérées
L'autorité de certification eMudhra a procédé à la révocation de huit certificats d'autorité intermédiaire supplémentaires. Cette décision découle des conclusions d'une enquête interne sur un récent incident de sécurité. Les investigations ont révélé une manipulation non conforme et inappropriée des clés cryptographiques privées lors du processus de génération des certificats, contraignant l'organisme à invalider ces éléments d'infrastructure à clé publique.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/emudhra-revokes-8-more-ca-certificates-after-private-key-mishap/)


## Menaces

### Démantèlement des infrastructures de Gootloader, CastleRAT et StealC
Europol et les services répressifs partenaires de neuf pays ont mené une opération conjointe majeure ayant permis la saisie de centaines de serveurs et de noms de domaine associés aux opérations malveillantes Gootloader, CastleRAT et StealC. Ces infrastructures servaient activement à orchestrer des cyberattaques et à propager des logiciels malveillants à l'échelle internationale. L'intervention coordonnée a neutralisé les composants techniques utilisés par ces cybercriminels pour commander leurs réseaux et exfiltrer ou exploiter des données compromises, marquant ainsi une perturbation significative de l'écosystème de ces menaces.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/police-dismantles-gootloader-castlerat-stealc-malware-infrastructure/)

### Opération CloudFire : vol de sessions Google d'entreprise par proxies actifs
Depuis la mi-août 2026, une campagne de phishing ciblée baptisée « Opération CloudFire » dérobe des sessions Google actives appartenant à des utilisateurs d'entreprise. Pour contourner les contrôles de sécurité habituels, les attaquants utilisent des invitations de calendrier et des serveurs mandataires (live proxies), rendant les liens totalement indétectables par les analyses automatisées classiques. L'équipe de recherche sur les menaces de Material Security, à l'origine de la découverte, a neutralisé des centaines de noms de domaine malveillants déployés par l'opérateur pour orchestrer cette campagne d'usurpation.

[The Hacker News](https://thehackernews.com/2026/11/calendar-invites-and-live-proxies.html)

### Attaques actives via ScreenConnect ciblant des MSP
L'éditeur ConnectWise enquête sur une campagne de logiciels malveillants active ciblant les fournisseurs de services gérés (MSP). Les attaquants exploitent des environnements ScreenConnect préalablement compromis afin de déployer des clients d'accès à distance illégitimes directement sur les machines et appareils des clients finaux. Cette opération malveillante a d'ores et déjà touché plusieurs dizaines d'organisations à travers les infrastructures de gestion administrées par les MSP ciblés.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/)

### Identification présumée de l'administrateur du groupe Qilin
Le gang Qilin s'est imposé comme le réseau d'affiliation ransomware le plus actif, revendiquant au moins 365 victimes en trois mois. Opérant depuis la Russie selon le modèle de la double extorsion, Qilin reverse au moins 80 % des rançons et collabore avec des affiliés anglophones comme Scattered Spider et RansomHub. Une enquête révèle des erreurs d'opsec de son administrateur, connu sous le pseudonyme « Haise ». Des messages récupérés sur le forum RAMP, saisi par le FBI, lient « Haise » au compte Telegram « Alexbigboss44 » et à un individu de 36 ans résidant à Saint-Pétersbourg.

[Krebs on Security](https://krebsonsecurity.com/2026/11/who-runs-the-ransomware-group-qilin/)

### Maersk victime d'un vol de données par le ransomware WhiteArmor
Le géant du transport maritime Maersk a confirmé avoir subi une violation de données après qu'un acteur malveillant s'est introduit sans autorisation dans un ancien système local hérité d'une acquisition passée. Le groupe d'extorsion à l'origine de l'attaque, WhiteArmor, a exfiltré des données depuis ce système d'information legacy et réclame une rançon s'élevant à 5 millions de dollars.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/maersk-confirms-data-breach-as-whitearmor-ransomware-demands-5-million/)

### La plateforme IA AntiFox liée à des attaques ciblant des secrets AWS
Des chercheurs en cybersécurité ont révélé les détails d'une campagne malveillante exploitant AntiFox, une plateforme émergente de tests d'intrusion reposant sur des agents d'intelligence artificielle. Cet outil a été détourné et utilisé par des cyberattaquants afin de dérober des identifiants et des secrets de production Amazon Web Services (AWS), permettant ensuite d'effectuer des mouvements latéraux au sein des environnements compromis. Selon les observations rapportées, plusieurs intrusions récentes ont démontré que des systèmes hébergés sur Alibaba Cloud, qui faisaient tourner des interfaces de la plateforme AntiFox, étaient directement associés à des actions malveillantes confirmées menées contre les cibles. Ces activités mettent en évidence le détournement d'outils avancés d'évaluation de sécurité à base d'agents IA pour automatiser et faciliter l'exfiltration de données d'authentification critiques et la compromission d'infrastructures cloud d'entreprises. Les organisations exploitant des environnements cloud sont incitées à surveiller les accès anormaux à leurs identifiants AWS et les connexions suspectes associées à ces infrastructures.

[The Hacker News](https://thehackernews.com/2026/11/antifox-ai-pentesting-platform-linked.html)

### Détournement de l'outil GSocket pour maintenir des accès persistants sur Linux
Plusieurs groupes d'acteurs malveillants détournent actuellement GSocket, un utilitaire open-source légitime dédié à l'accès distant, dans le but de maintenir une présence clandestine et persistante sur des serveurs Linux. Après avoir obtenu un accès initial en exploitant des vulnérabilités, les pirates installent cet outil afin de garantir la continuité de leur contrôle sur les machines ciblées. Ce mode opératoire leur permet de conserver un accès persistant, y compris après que les administrateurs ont corrigé les failles originellement exploitées pour l'intrusion.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-plant-gsocket-on-linux-servers-for-persistent-access/)

### Attaques ciblant ScreenConnect : 288 points de terminaison touchés dans 48 organisations
ConnectWise a procédé à la désactivation préventive de cinq extensions tierces dans les environnements de ses partenaires à la suite de signalements d'accès non autorisés. Les attaques constatées ont visé au moins 288 points de terminaison répartis dans 48 organisations différentes via des clients illégitimes. Dans un avis officiel, ConnectWise précise qu'aucun élément ne démontre une compromission de sa propre infrastructure ni l'existence d'une faille au sein même de son logiciel ScreenConnect, orientant les premières analyses vers des vecteurs tiers.

[The Hacker News](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html)


## Fuites et incidents

### Vol de secrets CI via le détournement massif de plus de 4 800 comptes GitHub
Selon Aikido Security, un cyberattaquant a utilisé des identifiants volés appartenant à 4 837 comptes GitHub pour implanter un voleur de secrets dans les dépôts sur lesquels ces comptes disposaient de droits d'écriture. Le script malveillant cible les secrets de configuration et les accès cloud accessibles par les pipelines d'intégration continue (CI). Il a été exécuté dans au moins 1 806 dépôts de code, permettant à l'assaillant de collecter des données sensibles et des identifiants associés aux environnements d'intégration continue des projets concernés.

[The Hacker News](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html)

### Apify fait l'objet d'une intrusion et révoque ses secrets internes
La société Apify a procédé à la rotation de secrets internes critiques et a révoqué plusieurs connexions OAuth tierces après avoir détecté un accès non autorisé à ses systèmes internes. En réponse à cette violation de sécurité, la plateforme impose également des réinitialisations de l'authentification à deux facteurs (2FA). Ces mesures d'urgence visent à contenir l'incident, à bloquer les accès persistants des attaquants et à sécuriser à nouveau l'ensemble des comptes et des intégrations connectées au service.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/apify-rotates-api-tokens-prompts-2fa-resets-after-breach/)

### Fuite de données chez un prestataire de Baker Tilly
Le groupe de conseil Baker Tilly Advisory Group a commencé à notifier ses clients à la suite d'un incident de sécurité chez un fournisseur tiers. Cette violation de données a entraîné la compromission d'informations personnelles sensibles appartenant à des clients ainsi qu'à leurs ayants droit ou personnes à charge. Baker Tilly informe les personnes concernées afin de préciser l'étendue de l'incident et les risques potentiels liés à l'exposition de leurs données chez ce tiers.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/baker-tilly-notifies-clients-of-data-breach-at-third-party-provider/)

### Piratage de Fireworks AI : conversations Notion AI exposées
La plateforme Notion a révélé qu'une violation de sécurité subie par Fireworks AI, son fournisseur d'infrastructure pour l'intelligence artificielle, a exposé des transcriptions de discussions de son service Notion AI. Cette fuite d'échanges a impacté un nombre restreint d'espaces de travail de la plateforme collaborative, illustrant les risques liés aux prestataires tiers dans la fourniture de fonctionnalités basées sur des modèles d'IA.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/notion-says-fireworks-breach-exposed-customer-ai-chat-transcripts/)


## Autres actualités

### Baisse de performances SQL Server due à des mises à jour Windows
Microsoft a officiellement confirmé que les mises à jour de Windows publiées depuis le Patch Tuesday d'octobre 2026 provoquent d'importants problèmes de performances et de stabilité affectant SQL Server. Les environnements exécutant ce système de gestion de base de données subissent des dégradations techniques directement liées à l'application de ces correctifs récents de l'éditeur. Microsoft a reconnu l'existence de ces dysfonctionnements et examine la situation pour remédier aux perturbations rapportées par les administrateurs.

[BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-recent-windows-updates-cause-sql-server-performance-issues/)

### Point d'étape sur l'opération REACTIV menée par l'ANSSI
Face à l'intensification notable des attaques cybercriminelles impliquant des violations de données qui affectent les services étatiques français, le Premier ministre a ordonné le 1er septembre 2026 à l'Agence nationale de la sécurité des systèmes d'information (ANSSI) d'instaurer un dispositif opérationnel renforcé baptisé REACTIV. Ce point de situation publié par le CERT-FR dresse le bilan d'octobre 2026 concernant la mise en œuvre de cette capacité accrue de réponse et de coordination face aux incidents visant les infrastructures publiques.

[CERT-FR](https://www.cert.cyber.gouv.fr/cti/CERTFR-2026-CTI-010/)

### Risques de sécurité liés aux plateformes de gestion des endpoints
Les plateformes de gestion des endpoints peuvent se transformer en outils d'attaque redoutables lorsqu'elles sont compromises par des acteurs malveillants. En obtenant un accès non autorisé à ces systèmes centraux, des pirates ont la possibilité de déployer des logiciels malveillants, d'exécuter des commandes à distance et de perturber le fonctionnement de milliers d'appareils connectés. Pour faire face à cette menace, la société Action1 met en avant une approche basée sur l'autorisation cryptographique contrôlée par le client. Cette méthode vise à empêcher les cyberattaquants d'abuser des opérations sensibles sur les endpoints.

[BleepingComputer](https://www.bleepingcomputer.com/news/security/your-endpoint-management-platform-could-be-your-biggest-security-risk/)

### Échecs d'installation des mises à jour de sécurité de novembre sur Windows 11
Microsoft a officiellement confirmé l'existence de dysfonctionnements concernant le déploiement de ses mises à jour de sécurité de novembre 2026. Selon l'éditeur, ces correctifs échouent à s'installer sur les systèmes exécutant Windows 11 qui avaient préalablement reçu la mise à jour de préversion (preview) du mois d'octobre. Ce blocage technique empêche l'application complète des correctifs mensuels prévus pour le système d'exploitation, laissant temporairement ces machines sans les derniers correctifs attendus. Les administrateurs gérant des flottes sous Windows 11 doivent prendre en compte cette anomalie signalée par Microsoft.

[BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-confirms-kb5132061-installation-issues-0x80070306-0x800f0989-0x800f0993-errors/)

### Webinaire sur la gestion des angles morts liés aux identités dans le SOC
Un webinaire spécialisé aborde la problématique croissante des angles morts liés aux identités au sein des centres des opérations de sécurité (SOC). Alors que les équipes de sécurité disposent d'un volume croissant d'alertes, de journaux et d'outils de surveillance, déterminer qui ou quoi est à l'origine d'une activité et quels sont ses accès autorisés reste complexe lors d'une attaque. Les événements suspects peuvent provenir d'un employé, d'un appel d'API inhabituel émis par un compte machine ou d'un agent d'intelligence artificielle accédant à des ressources sensibles. La session présente des méthodes pour identifier et fermer ces zones d'ombre.

[The Hacker News](https://thehackernews.com/2026/11/your-soc-sees-alert-but-does-it-know.html)
